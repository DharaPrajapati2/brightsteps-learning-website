# 🌈 BrightSteps

### Interactive Learning Platform for Children

BrightSteps is a colorful and interactive learning platform designed to make learning more engaging through **playful activities, simple games, visual interactions, and progress tracking**.

The goal is to create a friendly digital environment where children can learn at their own pace while parents can keep track of their learning activities.

---

## ✨ Features

- 👤 **Player Profiles** — Create and switch between learner profiles
- 🎮 **Interactive Games** — Fun learning activities designed around simple interactions
- 🍎 **Object Recognition Activities** — Learn through familiar objects and visuals
- 🎨 **Colour Learning** — Interactive colour-based activities
- 😊 **Feelings & Emotions** — Activities focused on recognizing emotions
- 🧩 **Matching Activities** — Improve recognition and memory through matching
- 📊 **Progress Dashboard** — Track scores, activities and learning progress
- 🔊 **Sound Controls** — Toggle interactive sounds
- 📱 **Responsive Design** — Designed to work across different screen sizes
- ☁️ **Supabase Integration** — Authentication and backend functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DharaPrajapati2/brightsteps-learning-website.git
```

### 2. Navigate to the project

```bash
cd brightsteps-learning-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

### 5. Start the development server

```bash
npm run dev
```

The application will run locally using Vite.

---

## 🔐 Security

Supabase configuration is loaded through environment variables.

The `.env` file is intentionally excluded from version control using `.gitignore`.

**Never commit private credentials, passwords, secret keys or service-role keys to GitHub.**
